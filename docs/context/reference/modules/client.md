# iPhone 用戶端模組（DeskPilot）

> **何時讀**：改 `DeskPilot/DeskPilot/` 任何檔（連線、顯示、手勢、鍵盤、量測），或遇到「黑畫面」「手感不對」「中文打不出來」時。
>
> 來源索引：根 `CLAUDE.md` 文件索引表。本檔是用戶端的單一事實源；協定細節見 `protocol.md`。

## 模組定位

iOS App。`ClientSession`（主執行緒狀態）＋ `ClientLink`（自己的序列佇列，負責網路與解碼）；畫面是 SwiftUI 包一個 UIKit 的 `RemoteSurfaceView`。影像路徑刻意**不經過主執行緒**：網路佇列收到 → 組 `CMSampleBuffer` → 交給 `AVSampleBufferDisplayLayer` 的 renderer，主執行緒卡頓也不影響畫面更新。

## 顯示

- 每個 sample 都標 `DisplayImmediately`：收到就顯示，跳過顯示層自己的緩衝。
- 顯示層掛上（或換新）時一律要一張關鍵幀重新開始；顯示層還沒準備好時收到的影格整段丟棄。
- renderer 狀態變 `.failed` 時 flush 並要關鍵幀。
- Hello 送的是手機原生像素（從 `UIWindowScene.screen.nativeBounds` 取，轉成寬 ≥ 高）。
- iOS 27 把 `status`／`flush()`／`enqueue` 標成 deprecated（新 API 是 `AVSampleBufferVideoRenderer.Receiver`，要搭配 render synchronizer），舊 API 仍可用，遷移列在待辦。

## 手勢（觸控板模式）

| 手勢 | 動作 |
|------|------|
| 單指滑 | 移動游標，有加速度（慢移 1 倍、快移最多 3 倍）；放大時位移除以 √zoom，比較精準 |
| 單指點 | 左鍵；連點兩下＝雙擊（主機依時間判定，手機不等待） |
| 雙指點 | 右鍵 |
| 雙指滑 | 放大中：**本地**平移檢視，不動 Mac 游標、不經網路，到桌面邊緣會停住；沒放大：捲動，換算成桌面 point。在手勢開始那一刻決定，中途捏合也不換 |
| 雙指捏合 | **本地**放大縮小（1～6 倍），以兩指中心為錨點，不經網路 |
| 長按 0.3 秒後拖 | 按住左鍵拖曳 |
| 三指滑 | 一律捲動 Mac（放大時要捲動用這個） |
| 四指滑 | Mac 系統手勢，**放開時**依方向送 ⌃ 組合鍵：左／右＝⌃→／⌃←（手指往左滑＝換到右邊桌面，同觸控板）、上＝⌃↑（Mission Control）、下＝⌃↓（App Exposé）；位移 < 60 pt 視為誤觸。四指進行中不當作捏合。依賴 Mac「系統設定 → 鍵盤快速鍵」裡這些項目維持預設開啟 |

**觸覺回饋**：左鍵（輕）、右鍵（中）、開始拖曳（中）、四指手勢觸發（中）、游標剛貼到桌面邊緣（硬，只在進入邊緣那刻一次）。

工具列只留螢幕切換、鍵盤、快捷鍵列、更多（聲音／省流量／統計／量測）、斷線。

## 快捷鍵列、剪貼簿、自動重連、省流量

- **快捷鍵列**（`ShortcutBar.swift`）：上方一排四個大按鈕（Mission Control ⌃↑、Spotlight ⌘Space、切換 App ⌘Tab、截圖 ⌘⇧5），下方是可橫向捲動的修飾鍵與按鍵列。⇧⌃⌥⌘ 是**黏滯修飾鍵**（`ClientSession.armedModifiers`），按一下武裝、用一次就放開；套用到快捷鍵列的按鍵，也套用到手機鍵盤打的下一個英數字。另有拷貝／貼上、方向鍵、Esc／Tab／Return、常用組合鍵。
- **剪貼簿**：「貼上」＝送手機剪貼簿文字到 Mac、200 ms 後送 ⌘V；「拷貝」＝送 ⌘C、300 ms 後向主機要 Mac 剪貼簿並寫進手機。刻意不做自動同步：iOS 16 起程式讀 `UIPasteboard` 會跳「允許貼上」提示，改成使用者按鈕觸發才合理。
- **自動重連**：只有「已連上過、沒被明確拒絕」的中斷才重連（延遲 1、2、3、5、8、10、15、20 秒，共 8 次），畫面停在最後一張並顯示提示；重連不再問 Face ID；回到前景會立刻重試；重連成功後重送畫質、省流量、聲音設定。第一次就連不上（IP 打錯、Mac 沒開）不重試，直接顯示失敗。
- **省流量偏好**自動／開／關，存在 UserDefaults；自動模式用 `NWPathMonitor.isExpensive` 判斷行動網路。WireGuard 通道本身不會被當成計量網路，所以要靠系統預設路由判斷。
- **聲音**：`AudioPlayer` 用 `AVAudioEngine` 播 AAC，排隊超過 10 塊（約 0.2 秒）就丟掉新封包，延遲優先。

雙指捲動與捏合同時辨識，捏合幅度超過 8% 才算縮放，避免兩者打架。游標是本地繪製的 CAShapeLayer，放大時游標靠近邊緣會自動平移畫面。

## 手動輸入 IP（外網）與配對

「在外面」輸入通道位址 `10.66.0.1` 連線，沒有 Bonjour 公告的主機 ID。行為與已知的坑見 `protocol.md`「配對與加密」（Keychain 保留舊紀錄、`authFailed` 重試迴圈、`forcePairNext`）。手機端的外網通道由官方 WireGuard App 提供，DeskPilot 本身不建通道。

## 連線前驗證本人

每次連線（區網或外網）前先跑 `LAContext.evaluatePolicy(.deviceOwnerAuthentication)`：Face ID，失敗可改輸入手機密碼；沒通過就不連。用意是手機遺失時，撿到的人拿不到 Mac 控制權。`Info.plist` 需要 `NSFaceIDUsageDescription`。外網用的「用 IP 連線」入口記住上次位址（`@AppStorage("manualHostAddress")`），沒有 Bonjour 主機 ID 時有任何配對紀錄就走驗證模式。

## ⚠️ 中文輸入要等組字結束

鍵盤用一個隱形 `UITextField`。**關鍵**：`markedTextRange != nil`（注音／倉頡還在選字）時不送；選字確認後才把整串文字送出並清空欄位。若逐字送，電腦端會收到注音符號或半成品。退格靠覆寫 `deleteBackward`（欄位是空的也會被呼叫）。黏滯的 ⌘ 鍵：按一下後，下一個英數字以 ⌘＋鍵碼送出（用 ANSI 鍵碼表），其餘文字照常走 Unicode。

## 內建量測（⏲ 按鈕）

約 25 秒，量測期間不要碰手機：
1. 靜止 8 秒：量閒置流量。
2. 40 個延遲探針（間隔 250 ms）：手機送 `probe` → 主機把探針編號標在「擷取時間晚於探針抵達」的第一張影格 → 手機收到該影格時計時。兩端都用手機時鐘，不需對時。主機視窗上有個色塊每次探針換色，製造畫面變化，所以**量測時主機視窗必須露在螢幕上**。
3. 捲動 8 秒：60 Hz 送捲動、每秒換方向，量捲動時的流量與 fps。

量到的延遲＝「手機送出 → 主機重繪 → 擷取 → 編碼 → 手機收到」，**不含**手機解碼上屏（約多一個 vsync）與觸控面板延遲。結果顯示在手機上並以 `report` 回寫主機 log。
